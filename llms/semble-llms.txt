# Semble

> Semble is a London-based cloud clinical and practice-management platform for UK private and independent healthcare. It exposes a single open, secure public GraphQL API at https://open.semble.io/graphql for reading and writing patients, bookings, availability, consultations, clinical pathways, prescriptions, labs, invoices, tasks, forms, questionnaires and webhooks. Authentication is a role-scoped token sent in the x-token header (a long-lived API token or a 12-hour signIn JWT). Rate limit: 240 requests/minute. Pagination is page-number based ({data, pageInfo{hasMore}}). The API is GraphQL-native and does not publish an OpenAPI or an HL7 FHIR CapabilityStatement.
